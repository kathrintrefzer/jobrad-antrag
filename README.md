# jobrad-antrag
Public UX lab for specifications, research, and agent experiments

## Zweck
Dieses Repository dient als zentrale Ablage für die UX-Arbeit am JobRad-Antrag: von der Forschung über Wireframes bis zum Design-System und zur finalen Dokumentation.

## Struktur

| Ordner | Zweck |
|--------|-------|
| [research/](research/) | Nutzerforschung und Marktanalyse: Interviews, Erkenntnisse, Personas, Use Cases |
| [wireframes/](wireframes/) | Wireframes, Skizzen und Klickdummies zur Konzeptvisualisierung |
| [design-system/](design-system/) | Design-System-Komponenten, Patterns und Tokens |
| [documentation/](documentation/) | Spezifikationen, Entscheidungen, Prozesse und Handovers |
